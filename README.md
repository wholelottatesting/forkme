# forkme

> A minimal, highly forkable starter repository.

## Overview

`forkme` is a deliberately small, open-source template meant to be forked as the
starting point for a new project. It ships with the conventions a healthy
repository needs — a README, a contributing guide, and a license — and nothing
else to get in your way.

## Getting started

1. Click **Fork** (or use `gh repo fork wholelottatesting/forkme`).
2. Clone your fork:
   ```bash
   git clone https://github.com/<your-username>/forkme.git
   cd forkme
   ```
3. Replace this README and start building.
